# بناء APK لتطبيق دفوعي قضيتي من الهاتف

## ماذا تحتوي هذه الحزمة؟
- `www/index.html`: نسخة من واجهة HTML المضمّنة في المشروع الأصلي.
- ملفات الأيقونة وmanifest.
- ملف Capacitor مبدئي لتغليف الواجهة داخل تطبيق Android.
- سير عمل GitHub Actions لإنشاء APK تجريبي قابل للتنزيل.

## مهم قبل الاستخدام الفعلي
هذه حزمة تغليف أولية وليست اعتمادًا أن كل وظائف المشروع الأصلي انتقلت إلى Android. المشروع الكامل يحتوي أيضًا على React/TanStack Start ومسارات وخدمات خادم؛ هذه الحزمة تستخدم واجهة HTML المضمّنة فقط، وهي تعمل بمخزن `localStorage` و`IndexedDB` الخاص بتطبيق Android. لا ترفع قاعدة بيانات قضايا فعلية ولا تعتبرها نسخة نهائية قبل اختبار تسجيل الدخول، الحفظ بعد إغلاق التطبيق، المرفقات، التصدير والاستيراد.

## تشغيل البناء من الهاتف
1. أنشئ مستودع GitHub خاصًا (Private) وارفع هذه الحزمة أو محتويات مجلد `mobile-android`.
2. افتح تبويب Actions داخل المستودع، وفعّل GitHub Actions.
3. شغّل workflow المسمى `Build Android APK` عبر زر Run workflow.
4. عند اكتماله، افتح ملخص التشغيل وحمّل artifact باسم `dafoei-qadiati-debug-apk`.
5. نزّل APK إلى Android، ثم افتح الملف واسمح بالتثبيت من هذا المصدر عند طلب النظام.

## خصوصية
GitHub Actions يحمّل الشيفرة إلى بيئة بناء سحابية، لكنه لا يحتاج إلى أي بيانات قضايا. لا تضع بيانات حقيقية أو ملفات نسخ احتياطي أو أسرارًا داخل المستودع.
